01. 适用范围与联系方式

本政策适用于泊记（ParkMemo）iPhone App、随附的小组件，以及本技术支持网站。泊记开发者负责本政策中说明的 App 数据处理和用户支持。隐私相关问题或请求，请联系 dev.mintolaw@gmail.com。

泊记帮助你记录停车位置、停车楼层、时间和照片。使用 App 无需创建账户。当前版本不集成广告 SDK 或第三方行为分析 SDK，也不会自动把你的停车记录、照片或传感器记录上传到开发者服务器。

02. App 处理哪些数据，以及为什么

  • 位置与常用地点：在获得定位授权后，处理精确位置、定位时间与精度、停车地点、你设置的地点名称及区域范围，用于保存停车位置、显示地址和监测停车区域。在你允许后台定位时，即使 App 不在前台，也可能接收定位或区域事件，以支持自动停车记录和楼层参考采集。
  • 气压、相对高度与楼层修正：通过系统传感器获取气压及相对高度变化，结合停车区域、停车事件和你手动修正的楼层，在设备上估算和校准楼层。此类学习在设备上完成。
  • 行程与停车记录：处理车辆连接或断开事件、停车时间、行程状态、楼层、停车时长及相关定位和传感器测量信息。车辆事件由你在 Apple 快捷指令中设置的自动化传入；泊记不会为了此功能扫描你周围的蓝牙设备。
  • 停车照片：你可自愿拍摄或通过系统照片选择器选取照片。App 处理所拍摄或选中的图片，并将其与停车记录一起保存到本机；不会要求浏览整个照片库。
  • 偏好与运行诊断：保存语言、楼层选项、通知开关和引导进度等设置。为支持功能运行与排查异常，App 还会在本机保存有限数量的诊断记录，可能包含事件时间、位置、区域、气压、权限状态及错误信息；当前最多保留最近 5,000 条，不自动发送给开发者。

03. 权限、小组件与通知

定位权限用于停车位置和停车区域监测；「运动与健身」权限用于读取气压及相对高度；相机权限仅在你选择拍摄停车照片时使用；通知权限用于显示自动停车保存结果。你可以拒绝或在 iPhone 系统设置中撤销相关权限，对应功能可能因此受限。

App 与随附小组件通过本机共享存储读取最近停车信息，不是向其他开发者分享数据。小组件和通知可能在主屏幕或锁定屏幕显示停车信息；你可以移除小组件、关闭通知或调整通知预览。停车通知为本地通知，不需要开发者推送服务器。

04. 哪些情况下数据会离开设备

  • Apple 地图及系统服务：地图显示、地点搜索、地址查询及导航会使用 Apple 的地图和定位服务。相关坐标、搜索词、地图区域或导航目的地等信息可能由 Apple 及其适用的服务提供方处理，具体依功能、地区及系统设置而定。请参阅 Apple 地图与隐私及 Apple 隐私政策。
  • 设备备份：泊记没有自建云端同步服务。设备上的 App 数据可能根据你的 iCloud 或电脑备份设置包含在系统备份中；备份由你和相应系统服务管理。
  • 主动联系支持：当你向开发者发送邮件时，我们会收到你的发件地址、邮件内容以及你主动附加的截图或其他文件，用于回复、排查问题和处理隐私请求。邮箱使用 Gmail，邮件会经过相关邮件服务提供方处理；请参阅 Google 隐私政策。请避免附上与问题无关的私人信息。

我们不出售你的个人信息，也不将其用于跨 App 广告追踪。除提供你请求的支持、你明确选择的分享，或适用法律要求的情形外，我们不会向无关第三方披露收到的支持信息。

05. 保存期限、删除与自主选择

停车历史、照片、校准数据和偏好通常保留在设备上，供后续使用；有限的诊断记录会随新记录产生而淘汰旧记录。你可在 App 中管理常用停车地点，或通过 iPhone 的「删除 App」移除 App 及其本机数据。「卸载 App」并保留文稿与数据不等同于删除；系统备份、你另行保存或分享的副本需要在相应位置单独管理。

如需停止后台位置处理，可在系统设置中关闭泊记的定位权限。你也可在「快捷指令」中停用或删除相关自动化，并在系统设置中关闭相机、运动与健身或通知权限。

我们仅在处理支持请求及必要后续跟进所需的期间保留支持邮件，或在适用法律要求的期间保留必要记录。你可以通过联系邮箱请求访问、更正或删除你发送给我们的信息，我们会按适用要求处理。开发者无法远程访问或替你删除仅保存在你设备上的停车数据。

06. 本网站、存储位置与安全

本网站不使用广告、访问分析脚本、追踪 Cookie 或在线反馈表单。语言选择通过网址参数传递；点击邮件链接只会打开邮件 App，是否发送由你决定。

网站由 GitHub Pages 托管。GitHub 会为安全目的记录访问者 IP 地址，即使访问者未登录 GitHub。请参阅 GitHub Pages 数据收集说明和 GitHub 隐私声明。托管、地图、备份及邮件提供方可能在你所在国家或地区之外处理数据，具体由所用服务及其政策决定。

App 本机数据受 iOS 的应用隔离和系统安全机制保护，网站使用 HTTPS。请妥善保护设备、系统备份和邮箱访问权限。没有任何存储或传输方式能够保证绝对安全。

07. 未成年人及政策更新

泊记并非专为儿童设计。若你是未成年人，请在需要时由监护人协助设置权限及联系支持。若你认为未成年人向我们发送了需要删除的个人信息，请联系开发者。

如果 App 功能或数据处理方式发生变化，我们会更新此页面及更新日期；需要额外告知或授权的变更，将按适用要求处理。你可随时通过本页邮箱询问当前政策。
